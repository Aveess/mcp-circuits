## Objetivo

tres flip-flops JK en cascada, reloj 555 astable de ~1 Hz, entrada EN (pausa),
RESET asíncrono, las siete funciones del punto 4 construidas con compuertas,
display de 7 segmentos y un sketch que ejecuta y demuestra las cuatro pruebas
del punto 5. El entregable documental es el **Markdown que genera el pipeline**
(reporte del build + bloque de documentación embebido). No hay PDF ni capturas
extra.

## Diseño eléctrico

### Contador

- `ff1` (74HC73, did 116723) → FF0 en la mitad 1; mitad 2 sin usar (J, K, CP a GND y R a GND: entrada CMOS nunca flotando).
- `ff2` (74HC73) → FF1 en la mitad 1 y FF2 en la mitad 2.
- Reloj: `t1.OUT` → `ff1.1CP`; `ff1.1Q` (Q0) → `ff2.1CP`; `ff2.1Q` (Q1) → `ff2.2CP`.
- `EN` (uno.D8) → J y K de las tres etapas.
- `RESET` (uno.D9, activo en alto) → `u?.1Y` = NAND(RESET, RESET) → `1R`/`2R` de ambos chips (activos en bajo).
- El 74HC73 dispara en flanco de bajada; el taller también pide flancos de bajada.

### Reloj 555

`Vcc → r1 (10k) → DIS`; `DIS → r2 (68k) → THR/TRIG`; `THR → c1 (10µF) → GND`; `CTRL → c2 (10nF) → GND`. Los dos resistores y `c1` van en la placa; el 555 y `c2` libres.

### Decodificador (27 compuertas NAND de 2 entradas + 3 XOR)

Expresiones del punto 4 (verificadas contra la tabla de verdad, 8/8 filas):

```
a = Q1 + ¬(Q2 ⊕ Q0)
b = ¬Q2 + ¬(Q1 ⊕ Q0)
c = Q2 + ¬Q1 + Q0
d = e + Q0·(Q2 ⊕ Q1)
e = ¬Q0·(Q1 + ¬Q2)
f = ¬Q1·¬Q0 + Q2·(¬Q1 + ¬Q0)
g = (Q2 ⊕ Q1) + Q1·¬Q0
```

Reparto físico (chip 74HC00 = 4 compuertas; ranura 1..4; `Y = NAND(A,B)`):

Cada salida `nX` va a su resistencia de 220 Ω y de ahí al segmento; el nodo de
la compuerta también se lee en `uno.A0..A6` para que el sketch verifique el
decodificador contra la tabla.

### Mapa de pines del Uno

| Pin | Uso |
|---|---|
| D2 | lectura de `t1.OUT` (mide el período) |
| D3, D4, D5 | Q0, Q1, Q2 |
| D8 | EN (salida) |
| D9 | RESET (activo en alto, salida) |
| A0..A6 | salida de las compuertas a..g (LOW = segmento encendido) |

### Sketch (secuenciador de pruebas)

1. Mide el período del reloj leyendo D2 y lo imprime.
2. RESET → espera 000 → `TEST:RESET=OK`.
3. EN=1: espera 16 transiciones, comprueba la secuencia 0..7..0..7..0 → `TEST:CICLO=OK`.
4. Deja avanzar a 5, EN=0, espera 3 períodos sin cambio → `TEST:EN0=OK`; EN=1, 2 transiciones → `TEST:REANUDA=OK`.
5. RESET en valor intermedio → 000 → `TEST:RESET_MEDIO=OK`.
6. En cada lectura estable compara los 7 segmentos con la tabla → `TEST:DECODER=OK`.
7. `TEST:FIN=OK`.

Toda lectura se hace con el valor estable 120 ms (dos muestras iguales
separadas 60 ms) para no leer el transitorio del acarreo asíncrono.

   ~27 s; la secuencia completa ronda los 50 s. `sim_wait_seconds` se fija
   **después** de medir el período real, no antes.

**Pasos**

   falsa que devuelve `[2, 1, 0, 0, 0]` → `(True, 0)`; con `[3, 3, 3]` y
   `timeout_s=0` → `(False, 3)`; con `evaluate` lanzando excepción → no propaga
   y devuelve `(True, 0)` (no se puede saber, no se bloquea el build).

   timeout_s=30.0, poll_s=0.3, required_zeros=3)`. Mover la constante y la

## Tarea 5 — Cerebro: netlist del decodificador y prueba de tabla de verdad

**Archivos:** `src/tinkercad_brain/decoder7.py` (nuevo), `tests/test_decoder7.py` (nuevo).

**Interfaz**

```python
@dataclass(frozen=True)
class Gate:
    chip: str      # "u1"
    slot: int      # 1..4
    out: str       # "nQ0"
    a: str         # senal de entrada o "GND"
    b: str

GATES: tuple[Gate, ...]            # 27 compuertas, en orden topologico
XOR_GATES: tuple[Gate, ...]        # 3 compuertas
SEGMENT_OUTPUT: dict[str, str]     # {"a": "na", ..., "g": "ng"}
LIT_TABLE: tuple[int, ...]         # mascara a..g por digito 0..7
def evaluate(q2: int, q1: int, q0: int) -> dict[str, int]
def segment_mask(q2: int, q1: int, q0: int) -> int
def signal_nets(producers: Mapping[str, str]) -> list[list[str]]
```

**Pasos**

1. Test primero (`tests/test_decoder7.py`):
   - `segment_mask` da la tabla del taller en las 8 filas (0x3F, 0x06, 0x5B,

   - 7 chips de 4 ranuras sin repetir (chip, ranura) y exactamente 27 compuertas;
   - toda señal de entrada de toda compuerta tiene productor;

     duplicados.

3. `signal_nets` arma una net por señal: `[productor] + [chip.slotA|B de cada
