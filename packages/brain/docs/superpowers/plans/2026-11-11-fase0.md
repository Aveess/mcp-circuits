# Fase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Medir si el puente ezhil sirve en vivo: fidelidad de lectura, latencia y granularidad de error de compilacion, antes de construir el cerebro.

**Architecture:** Tres frentes aislados sin solape de archivos (probe, fixtures, metrics) + un tester independiente que no participa en el desarrollo. Tinkercad es el destino unico; la Fase 0 viva requiere login, la infraestructura no.

**Tech Stack:** Python 3.14, stdlib solamente en Fase 0, pytest via unittest-compatible tests.

**Spec:** `~/.opencode/plan/v3-diff-asistente-tinkercad.md` secciones 6 (Anexo C) y 11.

## Global Constraints

- Destino unico: diseno guardado en Tinkercad. Ningun backend alternativo da el veredicto.
- Sin secretos en el repo ni en fixtures. Sin credenciales hardcodeadas.
- Cada agente trabaja SOLO en sus archivos declarados. Solape = tarea rechazada.
- Todo test se corre y se reporta con salida real. "Deberia pasar" no cuenta.
- Si la fidelidad medida es <90%, el diagnosticador se elimina del alcance.

## Review Focus

- Fixture con net esperado mal formado (pin inexistente) debe ser rechazado por el loader, no aceptado en silencio.
- Circuito vacio o sin nets no debe dividir por cero en metrics: score definido y documentado.
- Salida de probe con error del puente (ok=false) debe conservarse en el reporte, no descartarse.
- Texto de error de compilacion en espanol/ingles o vacio no debe clasificarse como exito.

### Task 1: Probe harness (Agente A)

**Files:** Create `src/tinkercad_brain/fase0/probe.py`, Test `tests/test_probe.py`
**Produces:** `ProbeStep(tool: str, arguments: dict)`, `ProbeRecord(tool, ok, elapsed_s, output)`, `run_steps(steps, call_tool) -> list[ProbeRecord]`, `records_to_jsonl(records) -> str`.

### Task 2: Fixtures ground-truth (Agente B)

**Files:** Create `fixtures/fase0/circuits.json`, `src/tinkercad_brain/fase0/fixtures.py`, Test `tests/test_fixtures.py`
**Produces:** `load_fixtures(path) -> list[dict]` validando: ids unicos, >=10 circuitos, cada uno con components>=1 y nets>=1, pins con formato `ref.pin`.

### Task 3: Metrics (Agente C)

**Files:** Create `src/tinkercad_brain/fase0/metrics.py`, Test `tests/test_metrics.py`
**Produces:** `compare_circuits(expected, actual) -> dict` con score 0..1 y detalle por componente/net; `latency_summary(samples: dict[str, list[float]]) -> dict`; `classify_compile_result(status_text, serial_text) -> str` en {"compile_error","running","unknown"}.

### Task 4: Tester independiente (Agente T, despues de integrar 1-3)

**Files:** Create SOLO `tests/test_tester_independent.py`
**Regla:** no modifica codigo de produccion. Pruebas adversarias sobre las interfaces publicas de Task 1-3; reporta fallos con evidencia al orquestador.
