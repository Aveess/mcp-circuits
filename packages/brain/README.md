# tinkercad-brain

Proyecto personal, local, un solo usuario.

Restriccion de diseno (no negociable): todo circuito producido termina como
diseno guardado en Tinkercad (`tinkercad.com/things/<id>/editel`), recargable
y editable a mano. Wokwi/avr8js/CircuitJS, si se usan, son solo contraste de
compilacion; nunca sustituyen al entregable ni al veredicto de simulacion.

Puente: repo privado `Aveess/tinkercad-mcp-bridge` (fork saneado de ezhil).
Sin secretos en el repo: credenciales solo en perfil persistente del navegador
o en `~/.config/jarvis/secrets/`.
